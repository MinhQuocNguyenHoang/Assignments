# Embedded Systems Assignments

This repository contains my Embedded Systems assignments, focusing on 
**common design patterns and programming techniques** used in embedded 
firmware development (Table-driven design, state machines, event-driven 
programming, etc.).

The goal is to strengthen my understanding of low-level programming, 
hardware interaction, and system design through hands-on practice with 
typical real-world examples.
